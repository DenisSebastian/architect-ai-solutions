# Geo-LLM: A Local Pipeline for Chilean Address Geocoding

An address is not just text. When it is treated carefully, it can become a coordinate, a spatial layer, and eventually decision-ready territorial information.

Geocoding sounds simple: transform an address such as "Av. Providencia 1208, Providencia, Santiago" into a point on a map. In practice, real addresses arrive incomplete, abbreviated, misspelled, duplicated, or ambiguous. Many operational workflows still solve this with manual cleaning or brittle rules.

Geo-LLM explores how language models can help structure addresses while remaining inside a traceable geospatial pipeline.

## The Pipeline

The current system combines:

1. Deterministic preprocessing for empty values, invalid communes, and obvious formatting issues.
2. Structured parsing through a local LLM with Ollama.
3. Geocoding through a local PostGIS provider, with optional Nominatim or hybrid fallback.
4. Spatial validation against the expected commune and region.
5. Street-name similarity matching against a local street master.
6. Batch execution, WebSocket monitoring, export, and map visualization through a Mission Control interface.

The system does not simply send text to a geocoder. It interprets the address, decides how to process it, validates the result spatially, and proposes corrections when the first attempt fails.

## Why This Pattern Matters

Address quality is a common bottleneck in logistics, public services, market analysis, health access studies, safety analysis, and urban planning. A more intelligent geocoding workflow can reduce manual review while keeping a clear audit trail.

The most important design principle is separation of responsibilities. The LLM helps parse and structure messy text, but PostGIS and spatial validation remain responsible for geographic truth.

## What Comes Next

The next lines of work are performance, user experience, coverage, credibility, and scalability. The direction is a robust operational service: configurable, explainable, and able to process real institutional address datasets without excessive infrastructure.

# Geo-LLM: un flujo local para geocodificación de direcciones chilenas

Una dirección no es solo texto. Cuando se trata con cuidado, puede convertirse en una coordenada, una capa espacial y, finalmente, en información territorial lista para apoyar decisiones.

Geocodificar parece simple: transformar una dirección como "Av. Providencia 1208, Providencia, Santiago" en un punto sobre un mapa. En la práctica, las direcciones reales llegan incompletas, abreviadas, mal escritas, duplicadas o ambiguas. Muchos flujos operativos todavía resuelven esto con limpieza manual o reglas frágiles.

Geo-LLM explora cómo los modelos de lenguaje pueden ayudar a estructurar direcciones sin salir de un flujo geoespacial trazable.

## El flujo

El sistema actual combina:

1. Preprocesamiento determinístico para valores vacíos, comunas inválidas y problemas evidentes de formato.
2. Análisis estructurado mediante un LLM local con Ollama.
3. Geocodificación mediante un proveedor local en PostGIS, con Nominatim opcional o respaldo híbrido.
4. Validación espacial contra la comuna y región esperadas.
5. Comparación de similitud de nombres de calles contra un maestro local de calles.
6. Ejecución por lotes, monitoreo con WebSocket, exportación y visualización cartográfica mediante una interfaz de control operativo.

El sistema no se limita a enviar texto a un geocodificador. Interpreta la dirección, decide cómo procesarla, valida espacialmente el resultado y propone correcciones cuando el primer intento falla.

## Por qué importa este patrón

La calidad de las direcciones es un cuello de botella común en logística, servicios públicos, análisis de mercado, estudios de acceso a salud, análisis de seguridad y planificación urbana. Un flujo de geocodificación más inteligente puede reducir la revisión manual y mantener una traza clara de auditoría.

El principio de diseño más importante es separar responsabilidades. El LLM ayuda a analizar y estructurar texto desordenado, pero PostGIS y la validación espacial siguen siendo responsables de la verdad geográfica.

## Qué viene después

Las siguientes líneas de trabajo son rendimiento, experiencia de usuario, cobertura, credibilidad y escalabilidad. La dirección es un servicio operacional robusto: configurable, explicable y capaz de procesar bases institucionales reales de direcciones sin requerir infraestructura excesiva.
