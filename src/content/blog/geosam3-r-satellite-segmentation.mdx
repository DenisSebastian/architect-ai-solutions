# GeoSAM3 in R: Prompt-Based Segmentation for High-Resolution Imagery

Object segmentation in high-resolution imagery usually demands labeled data, model configuration, and a workflow that can feel far from everyday geospatial analysis. The `{geosam}` package by Kyle Walker brings a different experience into R: prompt-based segmentation with SAM3 for satellite and aerial imagery.

In a quick set of experiments, I tested prompts such as "boats", "roads", and "buildings" over high-resolution scenes. The interesting part is not only that the model can return masks. It is that the output can be used as geospatial data.

## Why This Is Useful

For R users, the value is the continuity of the workflow. A user can work with georeferenced imagery, prompt the model, and export results as `sf` polygons for later analysis.

That turns segmentation into a step inside a spatial workflow rather than a separate computer vision project. It also lowers the barrier for rapid prototyping in urban analytics, infrastructure inventories, environmental monitoring, and field planning.

## Interaction Patterns

The package supports several prompt styles:

1. Text prompts, such as "pool", "boats", or "buildings".
2. Example prompts, where the user draws an object and searches for similar objects.
3. Point prompts, where a click guides extraction.
4. Confidence threshold control and direct export back to R.

This is especially promising for exploratory work. An analyst can test whether a category is separable before committing to a labeled dataset or a custom model.

## The Architectural Lesson

Tools such as `{geosam}` show how foundation models can become practical when they are wrapped inside domain-native workflows. The model is important, but the workflow is what makes it usable.

# GeoSAM3 en R: segmentación guiada por indicaciones para imágenes de alta resolución

La segmentación de objetos en imágenes de alta resolución suele exigir datos etiquetados, configuración de modelos y un flujo de trabajo que puede sentirse lejos del análisis geoespacial cotidiano. El paquete `{geosam}` de Kyle Walker lleva una experiencia distinta a R: segmentación guiada por indicaciones con SAM3 para imágenes satelitales y aéreas.

En una serie rápida de experimentos, probé indicaciones como "boats", "roads" y "buildings" sobre escenas de alta resolución. Lo interesante no es solo que el modelo pueda devolver máscaras. Es que la salida puede usarse como dato geoespacial.

## Por qué es útil

Para usuarios de R, el valor está en la continuidad del flujo. Una persona puede trabajar con imágenes georreferenciadas, guiar el modelo con indicaciones y exportar resultados como polígonos `sf` para análisis posteriores.

Eso convierte la segmentación en un paso dentro de un flujo espacial, en vez de un proyecto separado de visión computacional. También reduce la barrera para prototipos rápidos en analítica urbana, inventarios de infraestructura, monitoreo ambiental y planificación en terreno.

## Patrones de interacción

El paquete admite varios estilos de indicaciones:

1. Indicaciones de texto, como "pool", "boats" o "buildings".
2. Indicaciones por ejemplo, donde la persona dibuja un objeto y busca objetos similares.
3. Indicaciones por punto, donde un clic guía la extracción.
4. Control del umbral de confianza y exportación directa de vuelta a R.

Esto es especialmente prometedor para trabajo exploratorio. Un analista puede probar si una categoría es separable antes de comprometerse con un conjunto de datos etiquetado o un modelo personalizado.

## La lección de arquitectura

Herramientas como `{geosam}` muestran cómo los modelos fundacionales pueden volverse prácticos cuando se integran en flujos propios del dominio. El modelo es importante, pero el flujo de trabajo es lo que lo hace usable.
